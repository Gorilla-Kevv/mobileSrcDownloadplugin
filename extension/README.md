# ClipDown 跨端助手（Edge / Chrome 扩展插件）

> **ClipDown 多端协同官方扩展**：实现 Windows 电脑浏览器（Microsoft Edge / Google Chrome）与 Android 手机端的登录态共享、下载记录双向同步与网页媒体快捷嗅探。

---

## 🌟 核心价值

1. **共享登录态（彻底解决手机 Cookie 提取与风控难题）**：
   - 手机端 WebView 容易遭遇 Instagram、小红书等平台严苛的 2FA 验证码与风控死循环；
   - 用户在电脑 Edge / Chrome 正常登录后，插件可一键将有效会话 Cookie（包含 `sessionid`、`web_session`、`auth_token` 等）通过局域网秒传至手机；
   - 手机端收到后自动写入 `CookieStore` 并解除风控冷却，无需手动查看、复制繁琐代码或借助电脑调试！
2. **双向同步下载记录（仅同步元数据记录，不传输大文件）**：
   - 在电脑端随时查看手机下载过的所有历史记录（支持按平台、标题搜索、查看原帖直链）；
   - 跨端数据合并，不耗费大量流量传输视频大文件。
3. **网页媒体快捷嗅探与推送到手机**：
   - 在电脑浏览 Instagram、小红书、X、Bilibili 时，点击插件一键将当前帖子或视频「推送到手机下载中枢」，手机端悬浮球与后台下载引擎自动接管流水线。

## 🛠️ 安装方法（Edge / Chrome 2步极简加载）

无需打包或等待商店审核，直接加载解压缩源码即可：

### 1. Microsoft Edge 用户：
1. 在 Edge 地址栏输入 `edge://extensions` 并回车；
2. 在左侧菜单底部打开 **「开发人员模式」** 开关；
3. 点击顶部出现的 **「加载解压缩的扩展」** 按钮；
4. 选择当前仓库中的 **`extension`** 文件夹（即包含 `manifest.json` 的目录）；
5. 即可在浏览器工具栏看到 ClipDown 的紫晶护盾图标。

### 2. Google Chrome 用户：
1. 在 Chrome 地址栏输入 `chrome://extensions` 并回车；
2. 打开右上角的 **「开发者模式」** 开关；
3. 点击左上角的 **「加载已解压的扩展程序」**；
4. 选择当前仓库中的 **`extension`** 文件夹；
5. 加载完成！建议点击扩展拼图图标将 ClipDown 助手固定在工具栏。

## 📱 配对与使用流程

1. **手机端开启同步服务**：
   - 打开手机 ClipDown App → 进入「设置」页面；
   - 找到「🖥️ 电脑端插件与跨端同步」卡片，打开开关「启用局域网同步服务」；
   - 记下屏幕显示的 **服务地址**（例如 `http://192.168.1.108:8765`）与 **6位 PIN 码**（例如 `839201`）。
2. **电脑插件配对**：
   - 点击电脑浏览器右上角 ClipDown 图标；
   - 切换到「⚙️ 配对设置」标签；
   - 输入上述服务地址与 PIN 码，点击「测试连接并保存」；
   - 顶部状态指示灯变为 🟢 **已连接** 即表示配对成功！
3. **一键共享登录态**：
   - 在电脑上登录 Instagram、小红书或 X；
   - 点击插件「🍪 登录态共享」标签，点击 **「⚡ 一键同步所有 Cookie 到手机」**；
   - 手机端瞬时收到并自动提示保存成功，风控即刻解除！
4. **离线 / 跨网段备用**：
   - 若电脑与手机不在同一 Wi-Fi，可在插件中点击「📱 扫码同步」生成二维码，或「🔗 复制 DeepLink 协议」发给手机点击，即可完成离线导入。
