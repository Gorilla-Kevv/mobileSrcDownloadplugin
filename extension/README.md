## 🚀 双轨下载架构（电脑直接下载 + 推送手机）

每一个嗅探到的资源，插件均提供两种灵活的处理方式：
1. **💻 一键下载到电脑 (Downloads)**：
   - 依赖 Chrome / Edge 原生下载引擎，文件自动分类保存至电脑 `Downloads/ClipDown/<平台>/` 目录；
   - 支持图集一键批量多图全选下载。
2. **🚀 一键推送到手机**：
   - 通过本地 Wi-Fi 局域网直接将帖子链接提交至手机端 ClipDown 识别中枢，手机后台自动完成解析落盘进手机相册。
3. **页面内悬浮下载小部件**：
   - 浏览 X、Instagram、小红书、YouTube 时，页面右下角自动浮现紫晶下载按钮，无需每次打开插件弹窗即可直接点击下载或推送到手机。

## 🛠️ 安装方法（Edge / Chrome 2步极简加载）

无需商店审核，直接加载解压缩源码即可：

### 1. Microsoft Edge 用户：
1. 打开 Edge，在地址栏输入 `edge://extensions` 并回车；
2. 开启左下角的 **「开发人员模式」** 开关；
3. 点击顶部出现的 **「加载解压缩的扩展」** 按钮；
4. 选择当前仓库中的 **`extension`** 文件夹（即包含 `manifest.json` 的目录）；
5. 即可在浏览器工具栏看到 ClipDown 的紫晶护盾图标。

### 2. Google Chrome 用户：
1. 打开 Chrome，在地址栏输入 `chrome://extensions` 并回车；
2. 开启右上角的 **「开发者模式」** 开关；
3. 点击左上角的 **「加载已解压的扩展程序」**；
4. 选择当前仓库中的 **`extension`** 文件夹；
5. 加载完成！建议点击扩展拼图图标将 ClipDown 助手固定在工具栏。

## 📱 配对与使用流程

1. **手机端开启同步服务**：
   - 打开手机 ClipDown App → 进入「设置」页面；
   - 找到「🖥️ 电脑端插件与跨端同步」卡片，打开开关「启用局域网同步服务」；
   - 记下屏幕显示的 **服务地址**（例如 `http://192.168.1.108:8765`）与 **6位 PIN 码**（例如 `839201`）。
2. **电脑插件配对**：
   - 点击电脑浏览器右上角 ClipDown 图标；
   - 切换到「⚙️ 配对设置」标签；
   - 输入上述服务地址与 PIN 码，点击「测试连接并保存」；
   - 顶部状态指示灯显示 🟢 **已连接手机 (设备名)** 即表示配对成功。
3. **一键共享登录态**：
   - 切换到「🍪 登录态共享」标签，点击 **「⚡ 一键同步所有 Cookie 到手机」**；
   - 手机端瞬时收到并自动提示保存成功，风控即刻解除！
4. **离线 / 跨网段备用**：
   - 若手机与电脑不在同一 Wi-Fi，插件支持点击 **「📱 离线扫码同步」** 生成二维码供手机扫描，或 **「🔗 复制 DeepLink 协议」** 发送给手机一键唤醒导入。
